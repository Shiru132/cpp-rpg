# C++ RPG

Prosta gra RPG tworzona w C++ w celu nauki programowania obiektowego, zarządzania pamięcią oraz projektowania większego projektu.

A simple RPG game written in C++ for learning object-oriented programming, memory management, and larger project architecture.

---

## Aktualny stan projektu / Current project status

### Polski

- System klas postaci oparty na OOP
- Klasa bazowa `Character`
- Klasy pochodne `Warrior`, `Mage`, `Archer`
- System walki
- System potworów
- Rozdzielenie klas na pliki `.h` i `.cpp`
- Przygotowanie struktury pod `MonsterDatabase`
- Planowane wykorzystanie `std::vector` oraz smart pointerów

### English

- Character class system based on OOP
- Base `Character` class
- Derived `Warrior`, `Mage`, and `Archer` classes
- Combat system
- Monster system
- Classes separated into `.h` and `.cpp` files
- Structure prepared for `MonsterDatabase`
- Planned use of `std::vector` and smart pointers
