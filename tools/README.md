# Walidacja danych / Data validation

## Jak to działa? / How does it work?

### Polski

Walidator "przechodzi" przez wybrany plik z danymi i sprawdza ich zawartość według określonych reguł.

### English

The validator “analyzes” a selected data file and checks its content against specific rules.

## Jak odpalić / How to build

### Polski

Aby uruchomić walidator, w terminalu: 'cd cpp-rpg' a następnie 'python tools/validate_data.py'

### English

To run the validator, in the terminal: 'cd cpp-rpg' followed by 'python tools/validate_data.py'
